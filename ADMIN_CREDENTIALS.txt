ADMIN CONSOLE CREDENTIALS
=========================

To access the admin console (#/admin), you need superuser credentials.

SETUP:
------
1. Open terminal in the backend directory:
   cd backend

2. Activate virtual environment:
   source venv/bin/activate

3. Create superuser account:
   python manage.py createsuperuser

4. You will be prompted to enter:
   - Username: [enter your desired username, e.g., dagim]
   - Email: [enter your email]
   - Password: [enter secure password - enter twice]

EXAMPLE SETUP:
--------------
Username: dagim
Email: dagim@example.com
Password: YourSecurePassword123

LOGIN TO ADMIN CONSOLE:
-----------------------
1. Start the Django server:
   python manage.py runserver 8000

2. Start the frontend dev server:
   npm run dev

3. Navigate to: http://localhost:3000/#/admin

4. Enter the credentials you created:
   Username: dagim
   Password: YourSecurePassword123

ACCESSING ADMIN FEATURES:
-------------------------
Once logged in, you can:
- Manage Projects (create, edit, delete)
- Edit Site Settings (bio, headline, social links)
- View Contact Form Submissions
- Use AI-assist features (requires GEMINI_API_KEY)

SECURITY NOTES:
---------------
- Keep your password secure
- Don't share credentials publicly
- For production, use strong, unique passwords
- Enable HTTPS in production
- Consider 2FA if backend supports it

RESET CREDENTIALS:
------------------
To reset or create a new superuser:
   python manage.py createsuperuser

To list all superusers:
   python manage.py shell
   >>> from django.contrib.auth.models import User
   >>> User.objects.filter(is_superuser=True)
